# 스케줄표 사진 업로드

관리자 일정 화면의 `사진 스케줄 업로드`에서 A4 일일 스케줄표를 촬영하고,
분석 결과를 행별로 검수한 뒤 확정 일정으로 저장합니다.

## 저장 항목

- 날짜
- 시작 및 종료 시간
- 고객명
- 시술 종류(H/M)
- 담당 스텝과 배정 순서
- 비고

`기본가`, `실결제가`, `카드`, `계좌이체`, `현금` 정보는 분석하거나 저장하지 않습니다.
동명이인은 합치지 않고 사진의 각 행을 독립 예약으로 저장합니다.

## 작성 규칙

1. 시간은 `09:00-10:30`처럼 24시간제로 씁니다.
2. 고객 한 명은 상단 표의 한 행만 사용합니다.
3. 담당 스텝은 `지현`, `보니`, `하은` 또는 약칭 `지`, `보`, `하`로 씁니다.
4. 헤어는 `H`, 메이크업은 `M`으로 또렷하게 표시합니다.
5. 하단 배정은 `지현 09:00-09:30 M` 형식으로 씁니다.
6. 수정할 때 기존 글자는 한 줄로 완전히 지우고 같은 칸에 다시 씁니다.
7. 강조 색은 사용할 수 있지만 글자를 덮지 않게 표시합니다.
8. 문서는 평평하게 놓고 그림자, 손가락, 빛 반사가 없도록 촬영합니다.

## 촬영 및 검수

- 세로 A4 문서의 네 모서리를 화면 프레임 안에 맞춥니다.
- 수평선이 초록색으로 바뀐 상태에서 촬영합니다.
- 분석 신뢰도가 낮거나 글씨가 모호한 행은 주황색으로 표시됩니다.
- 고객명, 시간, 시술, 스텝 순서를 확인한 행만 선택해 업로드합니다.
- 같은 사진의 같은 행은 고유 표식으로 중복 등록을 막습니다.

## 서버 설정

Vercel Production에서는 자동으로 제공되는 `VERCEL_OIDC_TOKEN`을 사용해 AI Gateway에
연결하므로 별도 API 키가 필수는 아닙니다. 모델을 바꿀 때만 다음 환경변수를 설정합니다.

```text
SCHEDULE_VISION_MODEL=gpt-6.1-terra
```

Vercel 외부에서 직접 실행할 때만 서버 전용 `OPENAI_API_KEY`를 사용할 수 있습니다.
`OPENAI_API_KEY`는 HTML, Git 또는 클라이언트 환경변수에 넣지 않습니다.
